# Milestone 1: separate-process XPC boundary

Local Apple-silicon macOS validation on 4 October 2026:

- Swift tests: three passed, including valid capability, mismatched peer UID,
  wrong capability, unsupported version, expired/future deadline, unknown method,
  malformed/oversized bytes and unsafe configuration-file controls.
- Actual user launchd/XPC proof: nine rows passed. Service PID differs from the
  proof process; valid client requests succeed after every rejection.
- Deliberately wrong authorization oracle: exactly `bad-credential` fails;
  eight other rows pass and the proof exits 1. This validates the evidence
  checker, not an injected kernel identity or a claim of cross-user testing.
- Both proof runs verify the temporary launchd job is removed before returning.

The first attempt refused a valid configuration because Foundation rewrites
`/private/var` to `/var` during standardization. Directory permissions were
correct. Canonical filesystem identity now checks root separation while `lstat`
and `fstat` enforce final-entry type/ownership/permissions. The corrected unit
suite and both live proof modes passed; no authentication check was relaxed.

Reproduce with the README commands. No shared Wine/FEX source, build or prefix
was accessed. This milestone has no runtime operation or guest-launch claim.
Hosted CI results are recorded in the milestone PR after execution.
