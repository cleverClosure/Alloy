# Local catalog and operation proof — 4 October 2026

Milestones 1–5 of issue #102 run entirely on synthetic Steam libraries and
private Alloy content stores. No storefront account, real title, shared Wine
build, dependency download, or external artifact server participates.

- Catalog: two exact game/build pairs, stable pagination, empty and hostile
  controls, and the existing synthetic fingerprint
  `94f9ae3d556e33fcd4f7acfaa36e25521e3542e71e3c67ffa1004adadb6d2d1e`,
  cross-checked against the existing fingerprint CLI.
- Journal: all 49 state pairs, byte-identical replay, immutable terminals,
  conflicting payloads, corrupt records, and eight real process deaths at
  creation/transition write boundaries.
- Installation: real loopback fetch, multi-layer pause/resume progress, cancel,
  corrupted CAS plus materialized-link repair, stale uninstall rejection,
  repeated repair interruption, and 26 outer-journal/action SIGKILL cases.
- Content-store hooks: existing regressions plus stable activation replay,
  reference retirement and hard-link repair. Thirty-one separate process exits
  cover all 18 activation, nine repair and four uninstall boundaries.
- Storage: independent file/byte counts and exact removed digest sets over six
  generations; active, rollback and leased bytes survive; releasing the lease
  permits collection. Both partial and completed interrupted sweeps preserve
  the original before/after result.
- Consolidated CLI matrix: **163 PASS, 0 FAIL**, including all seven operation
  kinds, pause/resume/cancel state publications, failure-state publications,
  action completion and partial collection. Exact replay does not change file
  content, size or modification times. Saves survive uninstall and collection.
- Deliberately wrong repaired-byte oracle: **0 PASS, 1 FAIL**, exit 1, naming
  `independent repaired-byte oracle`. This proves the harness rejects a false
  expected result instead of merely collecting successful exit codes.

Reproduce with the two commands in the package README. JSON output records each
case name, verdict, elapsed time and failure text. Source-controlled fixtures
and named fault points permit rerunning without retaining private temp stores.
The proof is process-death recovery on macOS 27.0, not physical power-loss
injection. CI registration and an actual failing-then-green hosted run are the
last milestone and are recorded separately when observed.
