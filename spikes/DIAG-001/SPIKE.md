# DIAG-001 — offline diagnostics and privacy

Status: **Scoped offline synthetic proof passed**, 4 October 2026, issue #103.
This implements the local half of the diagnostics epic and the seven-class
bundle-only classification exercise. It does not implement the complete
client/daemon support service or close production privacy decisions.

## Hypothesis

A local harness can correlate events and actual native crash/hang observations,
exclude declared private content, remove known seeded secret patterns, and
export a bounded bundle whose privacy preview matches its contents before
consent. An independent classifier can identify each of seven deliberately
injected synthetic failures from that filtered bundle alone, and abstain when
a distinguishing signal is absent.

## Method

The Swift package has no external dependencies. Its nine correlation groups
follow operations doc 10 §5. Seventeen content classes map to all 21 named
category references in security doc 09 §17.1 and §18. Coverage tests derive the
required categories from that source document, so a newly added category cannot
silently escape the taxonomy.

The native subject triggers a known fatal error or blocks at a known semaphore.
LLDB provides symbolicated crash evidence; macOS `sample` captures the blocked
thread. Explicit execution/output bounds and a tested descendant identity census
cover clean exits, failed readiness, tool timeouts and cleanup.

Classified sensitive fields/documents are dropped wholesale. Permitted text is
also scanned for the documented credential, token, path, sensitive URL and
marked-content grammar. Metadata is checked before export. Literal fixtures
and three reproducible grammar-fuzz seeds measure both detection and unchanged
clean bytes. This is classification plus bounded pattern recognition, not a
claim to recognize every possible secret or private prose.

The local builder creates private-permission files with a manifest, content
hashes, exact retained class inventory and a pre-consent preview. Raw native
stacks are excluded; typed cause summaries remain. A strict reader verifies
membership, sizes, hashes, paths, encoding and redaction stability. Upload is
explicitly unavailable at every consent level.

Seven scripted operations generate the failure evidence. The classifier sees
only verified bundles after scratch state is removed. The eighth bundle differs
from the observed guest crash by one removed process-role field. Fresh fixture
generation, disabled injections, missing-signal controls and conflicting
evidence test both successful identification and refusal to guess.

## Pass/fail criteria

| Criterion | Passing evidence |
| --- | --- |
| Correlation model | Required/optional identity groups round-trip; golden JSON and malformed cases pass |
| Taxonomy | All 21 source-document category references map exactly once to 17 cases |
| Native crash | Actual fatal error names its known function/source; clean exit yields no report |
| Native hang | Actual sampled blocked site; fast exit yields no snapshot |
| Lifecycle | Timeout, overflow, readiness failure and verified descendant cleanup controls fire |
| Literal redaction | 20 planted values, zero survivors; 316-byte clean fixture unchanged |
| Randomized redaction | Three logged seeds, 360 insertions each, 100% caught |
| Bundle/preview | Actual exported membership and class union equal the pre-consent preview |
| Local privacy boundary | All ten sensitive classes excluded; malformed/sensitive exports fail; no networking API |
| Classifier | Seven correct causes; eighth insufficient evidence; disabled/missing/conflicting controls abstain |
| Isolation | No protected docs package, CI workflow, third-party source or shared runtime changes |

The [dated result](results/2026-10-04-01-offline-diagnostics.md) records commands,
counts and scope. The [committed eight-bundle fixture set](prototype/Tests/AlloyDiagnosticsTests/Fixtures/oracle/oracle.json)
is generated by the same executable laboratory used in fresh tests.

## Reproduce

On an Apple Silicon Mac with Xcode command-line tools and Swift 6:

```sh
swift test --package-path spikes/DIAG-001/prototype
```

This terminal command is the full local oracle; no game, account, daemon,
consent choice, GUI or network is required. The package is intentionally not
registered in hosted CI for this issue. Repository lint still runs in each PR.

## Limits and next integration work

The provider/profile cases use synthetic file selection. The memory case is a
bounded allocator quota failure, not physical host pressure. Shader and guest
roles use an actual native fatal-error process with a laboratory-assigned role;
no real compiler or Wine process is exercised. The classifier's success is
limited to these explicit signal contracts.

Hash seals detect accidental modification, not malicious rewriting. Exports
are local plaintext protected by filesystem permissions, not encrypted storage.
Concurrent hostile filesystem mutation, arbitrary-process containment, unknown
secret grammar, and semantic re-identification are outside this proof.

DIA-001–004 and DIA-009 are implemented only at their offline/local scope, with
synthetic DIA-005 hang observation. Live client/daemon/provider integration,
DIA-006/007/008/010, upload encryption, support issue clustering, production
retention, regional consent defaults and PRIV-001 remain future work. No
shipped consent default is selected. The evidence reduces the zero-code gap
behind R-020/R-026; it does not retire those production risks.
